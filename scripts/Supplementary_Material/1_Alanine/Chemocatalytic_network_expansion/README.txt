1. README
   This folder contains the script needed to reproduce the alanine reaction network results discussed in the manuscript.

2. Important Notice
   DORAnet is under active development, and new reaction rules are continually added. Running the latest version may yield slightly different molecule or reaction counts than those reported in the manuscript. These differences do not affect the validity of the discussion or conclusions.

3. Reproducing the Exact Numbers
   To reproduce the exact counts reported in this study, install the version of DORAnet used:

   pip install doranet==0.5.5a1
