Running DORAnet on Sanitized USPTO Reactions
Place the sanitized reaction sets (Sanitized_reactions_onlyCHO.csv, Sanitized_reactions_onlyN.csv, Sanitized_reactions_onlyS.csv) into the working directory.

Files and Descriptions
Reaction_Smarts.py
Contains chemocatalytic reaction rules used by DORAnet.

DORAnet_benchmark_onlyCHO.py
Runs DORAnet to reproduce reactions in the onlyCHO subset.

DORAnet_benchmark_onlyN.py
Runs DORAnet to reproduce reactions in the onlyN subset.

DORAnet_benchmark_onlyS.py
Runs DORAnet to reproduce reactions in the onlyS subset.
